# ToletEarth

A broker-free rental platform for Chandigarh, Mohali and Panchkula — owners list
properties directly, tenants search and contact them with no brokerage.

## Stack

- **Backend:** Flask (application factory + blueprints)
- **Database:** SQLite (`instance/toletearth.db`)
- **Frontend:** Jinja2 templates, Bootstrap 5, Poppins (Google Fonts), Bootstrap Icons

## Project structure

```
ToletEarth/
├── app/
│   ├── __init__.py        # app factory, registers blueprints
│   ├── models/db.py        # SQLite connection, scoped per request
│   ├── routes/              # main, properties, owner blueprints
│   ├── services/             # data-access layer (all SQL lives here)
│   ├── templates/
│   └── static/
├── migrations/
│   ├── 001_initial_schema.sql
│   └── seed_db.py            # builds + seeds instance/toletearth.db
├── instance/toletearth.db     # committed for now (seed/demo data only)
├── config.py
├── run.py
└── requirements.txt
```

## Setup

```bash
git clone <your-repo-url>
cd ToletEarth
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Database

The repo ships with a seeded `instance/toletearth.db`, so you can skip this step
to try the app immediately. To rebuild it from scratch (drops and recreates all
tables, reseeds sample data):

```bash
python migrations/seed_db.py
```

## Run

```bash
python run.py
```

Visit `http://localhost:5000`.

## Routes

| Route | Description |
|---|---|
| `/` | Home — hero, search, stats, featured properties |
| `/properties` | Browse all listings, with location/type/BHK/budget filters |
| `/property/<id>` | Property detail page |
| `/list-property` | Post a property (form only — not yet wired to the database) |
| `/about` | About |
| `/contact` | Contact form |
| `/faq` | FAQ |

## Status / known gaps

- `/list-property` and `/contact` forms don't persist submissions yet.
- `properties.html`, `property_details.html`, `about.html`, `contact.html`,
  `list_property.html`, and `faq.html` are functionally correct but not yet
  re-skinned in Bootstrap (still reference an older stylesheet).
- No authentication yet — `users` table exists but there's no login/register flow.
- Images are on-brand placeholders, generated by `app/static/images/generate_placeholders.py`.
  Swap in real property photos before going live.
